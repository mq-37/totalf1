How we normalize points

Historical point systems changed often (e.g. only top 5 scored, then top 6, top 8, top 10; different values for 1st–10th). To compare drivers across all eras fairly, we use a single modern scheme for the All-Time ranking.

  • Primary method: Every race result is re-scored with the 2025 points system: 1st = 25, 2nd = 18, 3rd = 15, 4th = 12, 5th = 10, 6th = 8, 7th = 6, 8th = 4, 9th = 2, 10th = 1. Only finish position is used (no fastest-lap bonus).
  • Fallback for older seasons: We apply this per season. For any year where we don’t have per-race finish positions (e.g. 1950s–1960s), we scale that season’s championship points so the champion’s total equals “races × 25”, then sum across seasons. So drivers like Jack Brabham get a fair normalized total for their whole career, including eras with no per-race data.
  • World championship bonus: Drivers are rewarded for world titles. We add +200 points per world championship to the ranking total. Ranking order uses this adjusted total; the “Points” on each card is the raw re-scored total, with “Title bonus” shown separately.

Ranking uses (normalized points + title bonus), then wins, fastest laps, podiums, and starts as tie-breakers.
